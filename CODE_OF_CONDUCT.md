# Code of Conduct

DebArk contributors and maintainers are expected to keep project discussions welcoming, respectful, and focused on the work.

Unacceptable behavior includes harassment, personal attacks, discrimination, intimidation, and publishing someone else's private information without permission. Critique code and ideas directly, without targeting people.

Maintainers may remove content or restrict participation when needed to keep the project usable and safe. To report a conduct concern, contact the maintainer privately through the GitHub profile linked from this repository.
